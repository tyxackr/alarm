# ⚠️ weather-warn-audit

> **气象预警审核 SOP** —— 气象台预警信息录入「突发预警信息发布平台」前的最后一道审核。

适用于 OpenClaw / Hermes 等 agent 框架；亦可人工直接按 SOP 走。

## 🚨 这是什么

一个审核工具/规范，用于在气象台预警信息（如雷电、大风、冰雹等）录入「突发事件预警信息发布平台」前，按 6 条审核规则逐项检查。

## 📦 安装

### 方式 A · OpenClaw

```bash
cp -r . ~/.openclaw/skills/weather-warn-audit/
```

或软链：

```bash
ln -s "$(pwd)" ~/.openclaw/skills/weather-warn-audit
```

### 方式 B · Hermes / 其他

参考对应框架的 skill 加载路径。

## 🚀 使用

agent 收到预警截图后调用本 skill，按 SKILL.md 的「输出格式（固定完整版）」输出 7 个 section：

```
📸 读图结果 → 📋 审核报告 → 🚨 严重 → ⚠️ 重大 → 💡 提示 → ✅ 已合规项 → 🎯 结论
```

详见 [SKILL.md](./SKILL.md)。

## 📋 6 条审核规则

| 级别 | # | 规则 |
|------|---|------|
| 🚨 严重 | 1 | 错别字、重复用字 |
| 🚨 严重 | 2 | 标点符号重复使用 |
| 🚨 严重 | 4 | 内容与标题/时间/灾种/地区不一致 |
| 🚨 严重 | 5 | 严重语病 |
| 🚨 严重 | 6 | 发布渠道未勾选「12379 短信」（必勾） |
| ⚠️ 重大 | 3 | 标点符号错误使用 |

规则编号故意留 3 在「重大」段（与历史版本兼容），新规则沿用 4-6 顺延。

## 🧷 关键铁律

1. **必须有图依据**——无图不审（避免幻觉编造审核记录）
2. **必须返回读图结果**——让调用方核对「我看到了什么」
3. **必须按完整模板输出**——7 个 section 必填，0 处问题也显示「（0 处）无」
4. **必须等人工复核才入模板库**——AI 结论不直接入库（避免污染）
